# StudyMaster - Cross-Platform Learning App

A comprehensive learning app that works on **mobile, Windows, and Mac/iMac**! This is a Progressive Web App (PWA) that can be installed on any device.

## Features

✨ **Flashcards** - Interactive flip cards to memorize terms and definitions
📝 **Multiple Choice Quizzes** - Test your knowledge with A/B/C/D options
✏️ **Practice Exercises** - Solve problems and see solutions
📊 **Progress Tracking** - Monitor your learning progress and accuracy
🎨 **Create Your Own Content** - Add custom flashcards, quizzes, and exercises
📱 **Works Everywhere** - Mobile, Windows, Mac, and any device with a browser

## How to Use

### Option 1: Open Directly in Browser (Easiest)
1. Open the `index.html` file in any web browser
2. Start studying immediately!

### Option 2: Run as a Local Server (Recommended for Mobile)
1. Install a simple server (if you have Python):
   ```bash
   python -m http.server 8000
   ```
2. Open your browser and go to: `http://localhost:8000`
3. On mobile, connect to the same WiFi and use your computer's IP address

### Option 3: Install as an App (Mobile)
1. Open the app in your mobile browser (Chrome/Safari)
2. Tap the "Share" or "Menu" button
3. Select "Add to Home Screen" or "Install App"
4. The app will now work like a native app!

## Creating Your Own Content

1. Go to the "Create Content" section
2. Choose between Flashcards, Quiz Questions, or Exercises
3. Fill in the form and click "Add"
4. Your content will be saved and available immediately!

## Features Detail

### Flashcards
- Tap cards to flip between front and back
- Mark cards as "I Know This" or "Need Practice"
- Navigate through decks with Previous/Next buttons
- Progress is tracked automatically

### Quizzes
- Multiple choice questions with A, B, C, D options
- Instant feedback on correct/incorrect answers
- Progress bar shows quiz completion
- High-level quiz statistics tracked

### Exercises
- Type your answer in the text area
- Submit to check against the solution
- View explanations for how to solve
- Perfect for practice problems

### Progress Tracking
- View total flashcards studied
- Track quizzes completed
- Monitor exercises done
- See your overall accuracy rate
- Recent activity log

## Technical Details

- **Pure HTML/CSS/JavaScript** - No dependencies needed
- **Local Storage** - Your progress and custom content are saved in your browser
- **PWA Ready** - Can be installed as a native app on mobile devices
- **Responsive Design** - Works on phones, tablets, and desktops
- **Offline Capable** - Once loaded, works without internet

## Creating App Icons (Optional)

To create the app icons for installation:
1. Open `create-icons.html` in your browser
2. It will automatically download `icon-192.png` and `icon-512.png`
3. Place these files in the study-app folder

## Tips

- All your data is saved locally in your browser
- Clearing browser data will reset your progress
- The app works best when installed as a PWA on mobile
- Use the "Create Content" feature to personalize your learning

## Support

If you have any issues or questions, the app is self-contained and should work on any modern browser (Chrome, Firefox, Safari, Edge).
